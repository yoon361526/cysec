Integrated Cryptocurrency and Cyber Threat Intelligence Platform ＋
  • On-chain Intelligence
  • Knowledge Graph
  • Digital Forensics

This platform integrates and analyzes data scattered across the dark web, encrypted messaging services, social media, and blockchain networks to uncover connections between cryptocurrency-related crime and cyber threats. Users can monitor dark web crawling activity and search collected URLs, cryptocurrency addresses, email addresses, and messaging accounts. The platform also provides real-time visibility into data collection across channels such as Telegram, Session, and SafeW. It traces transaction relationships and potential cross-chain links involving major cryptocurrencies, including Bitcoin and TRON. Using on-chain intelligence, the platform visualizes fund flows and connections among criminal organizations, exchanges, and wallet addresses. Data from the dark web, messaging services, social media, and blockchain networks is consolidated into a unified knowledge graph, while large language models (LLMs) identify key entities and analyze significant relationships within each case. The platform can also collect wallet addresses, transaction records, relevant applications, and other cryptocurrency-related artifacts from seized or otherwise acquired cold wallets, computers, and digital devices. These findings can then be correlated with on-chain analysis results. When a case is registered through the agent console, the platform automatically performs the associated data collection, tracing, and analysis workflows, reducing the time and repetitive work required for investigations. The platform can be used for cryptocurrency crime investigations, anti-money laundering and fund tracing, digital forensics, cyber threat intelligence, and the analysis of connections between criminal organizations.

MCP- and AI Agent–Powered Platform for Automated Cryptocurrency Threat Analysis ＋
  • MCP Orchestration
  • Cross-chain Tracing
  • LLM Analysis

This AI-powered threat analysis platform connects dark web crawlers, encrypted messaging services, cryptocurrency tracing engines, on-chain intelligence, and knowledge graph analytics through MCP-based modules. Users can monitor data collected from the dark web and channels such as Telegram, Session, and SafeW, while accessing consolidated information on suspicious accounts and cryptocurrency addresses. The cryptocurrency tracing module tracks transaction flows and connections between addresses across major blockchains, including Bitcoin and TRON. It also visualizes clusters of high-risk addresses and indicators of cross-chain asset movements. The module analyzes fund-obfuscation patterns such as Split, Peel, and Merge, in which funds are distributed across multiple addresses or later recombined, to identify potential money laundering activity and indirect transaction routes. Using on-chain intelligence, users can access label data associated with threat groups such as the Lazarus Group, along with information on related wallets and exchanges. An LLM then identifies the most relevant indicators and relationships for each case. Data collected from the dark web, encrypted messaging services, social media, and blockchain networks is integrated into a unified knowledge graph. Users can ask the LLM to analyze key nodes and their relationships, while the agent console automatically handles case-specific data collection, asset tracing, relationship analysis, and result organization. The platform can be used for cryptocurrency crime investigations, cyber threat intelligence, fund-flow tracing, criminal network analysis, and digital asset risk monitoring.

XRange: An AI Agent-Based Social Media Attack–Defense Simulation Platform ＋
  • Attack–Defense
  • Real-time Agents
  • Content Moderation

XRange is a social media simulation platform that recreates user and AI agent activity, content spread, and interactions in a realistic SNS environment. It supports posting, quoting, reposting, likes, follows, search, and profiles — letting you watch AI criminal and investigator agents generate content and react in real time. The admin console manages account and agent status with unified access to posts, media, and behavior logs. Suspensions and reinstatements, post moderation, admin action records, and attack–defense round progress are all tracked, keeping large multi-agent experiments running stably. Useful for cybercrime response training, misinformation and opinion-spread analysis, AI agent behavior validation, and social media threat scenario research.

PRODUCT DEMO VIDEO

XRange Unified Account & Agent Management System ＋
  • Account Operations
  • Audit Logs
  • Bulk Control

An administrator system for centrally managing the many platform accounts and AI agents running in a social media simulation environment. You can review each account's linked agent, visibility scope, post and follower counts, and operational status, then suspend, reinstate, or delete accounts individually or in bulk. Agent roles, personalities, creation dates, and running states are all visible on a single screen, and agents no longer in use once an experiment ends can be selected and deleted in batches. Before deletion, the system explains the scope of impact, warns that the action is irreversible, and records the reason for each action — preventing operational mistakes and keeping a clear audit trail. Useful for running large-scale AI agent experiments, managing virtual accounts, organizing research data, and providing administrative control over social media simulation environments.

PRODUCT DEMO VIDEO

Multi-Persona AI Social Behavior Simulation System ＋
  • Persona Engine
  • Behavior Simulation
  • Experiment Analytics

A simulation system for creating AI agents with different ages, occupations, interests, personalities, and social media habits, then testing how they behave in a virtual social media environment. Personas can be configured manually or generated at random, with control over tone of voice, use of profanity, activity level, attitude toward others, behavioral tendencies, and image-posting probability. After selecting the agents for an experiment, you set the run duration, round interval, image generation, forced login, and activity conditions to launch a multi-agent run. Agents autonomously post, comment, like, quote, repost, and follow, with the results visible directly in the platform feed. Once an experiment ends, you can review participating accounts, generated posts, content exposure, behavior logs, and each agent's decision output by round. Useful for AI persona behavior validation, content diffusion research, misinformation countermeasure experiments, social media user response analysis, and cyber attack–defense scenario evaluation.
